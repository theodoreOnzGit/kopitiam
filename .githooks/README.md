# .githooks — KOPITIAM git hooks

Tracked, version-controlled git hooks for this repo. Activated per-clone with:

```sh
git config core.hooksPath .githooks
# or, equivalently:
scripts/install-git-hooks.sh
```

`core.hooksPath` is local git config (hooks are never cloned automatically), so
each working copy runs the install step once. Pointing at this directory also
means git ignores `.git/hooks/` **and** the stale `.beads/hooks/` scaffolds,
which were generated by an incompatible beads build (they call `bd hooks run`,
a subcommand the installed `beads-rs` does not provide) and would abort commits.

## Hooks

| Hook | Language | Purpose |
|---|---|---|
| `prepare-commit-msg` | Python 3 (stdlib only) | Stamps a standard `Token-Cost:` trailer on every commit — AI token-cost accounting recorded in durable git history. |

### `Token-Cost` trailer

Idempotent (safe across `--amend`/rebase), skips merge/squash commits. Populate
real figures via the environment for the session that produced the commit:

| Env var | Meaning |
|---|---|
| `KOPITIAM_TOKENS_IN` | input/prompt tokens |
| `KOPITIAM_TOKENS_OUT` | output/completion tokens |
| `KOPITIAM_TOKEN_COST_USD` | dollar cost |
| `KOPITIAM_AI_MODEL` | model id (e.g. `north-mini-code`) |

With nothing set the trailer reads `Token-Cost: unmetered` — an explicit,
non-fabricated record that the commit was not instrumented.

Example:

```
Token-Cost: 12,345 in / 6,789 out tok; $0.42; model=north-mini-code
```

## Beads

Issue tracking uses `beads-rs` (`bd`), which syncs through its own daemon
(`bd sync`), not git hooks — so no beads hook lives here. See `AGENTS.md`.

## Upstream drift

Each ported/diverged entry records the upstream `commit` it was translated from.
The generator is offline and deterministic, so it does **not** fetch upstream.
To check drift, out of the deterministic path:

```sh
# for an entry with upstream U and recorded commit C:
git ls-remote <U-url> <ref>          # newest upstream SHA for a ref
# if it differs from C, diff the cited source path between C and the ref
# in a local clone to see whether the ported region actually moved.
```

`scripts/port-ledger.sh --drift-check <ref>` documents this compare plan.

**Confidence:** High (reproduced 2026-08-01). **Owns:** `apps/cli/src/main.rs`

## Problem

Orienting in this repo, `kopitiam tokens crates/ --tree` reported:

```
crates/  74135961 tokens (22673 files)
  kopitiam-ai/  66959903 tokens (20830 files)
    vendor/  66903180 tokens (20813 files)
      OpenFOAM-dev/  40633875 tokens (17566 files)
        tutorials/ ...
```

**90% of the reported total is `kopitiam-ai/vendor/OpenFOAM-dev`**, mostly CFD mesh geometry. The first 25 lines of output were entirely vendored tutorials.

The tool built to make budgeting cheap gave an answer dominated by files no agent will ever read, and I had to re-run with explicit crate paths.

## Change

Default-exclude `vendor/`, `target/`, `node_modules/`, `.git/`; add `--include-vendor` to restore.

**Preferred:** report them as a single collapsed line rather than omitting silently —

```
vendor/  66959903 tokens (20813 files) [excluded]
```

— which is honest and equally cheap.

## Acceptance

- [ ] `tokens crates/ --tree` surfaces the real source tree within the first screen.
- [ ] Vendored totals shown as one collapsed line, not expanded.
- [ ] `--include-vendor` restores current behaviour.

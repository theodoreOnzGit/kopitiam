# `skeleton-gen.sh` — sample output (Task III-3, skeleton-first translation)

`scripts/skeleton-gen.sh` mechanically turns a vendored source file into Rust
signature **stubs** so a porting agent writes bodies only. It is a deterministic
tool (§0.3), honest about being a regex/brace heuristic rather than a real
parser: every skeleton carries a `SKELETON-GEN: review` banner and an inline
found/skipped tally, and `--report` prints the full breakdown so nothing is
silently dropped.

Everything below is verbatim tool output. Re-run the command above each block to
reproduce it byte-for-byte.

---

What the heuristic did, from the C signature
`int fz_glyph_entirely_outside_box(fz_context *ctx, fz_matrix *ctm, fz_text_span *span, fz_text_item *item, fz_rect *box)`:

* `fz_` prefix stripped from the function name; the `// MuPDF:` breadcrumb keeps
  the 1:1 map findable (AID-0051 §1).
* `fz_context *ctx` **dropped** (AID-0051 §5: context → Rust ownership).
* `fz_matrix *` → `&mut Matrix`, `fz_text_span *` → `&mut TextSpan`,
  `fz_rect *` → `&mut Rect` (canonical names from AID-0051 §3; generic
  `fz_<x>` → PascalCase for the rest).
* `box` → `box_` (Rust reserved-word guard).
* `int` return → `i32`; the `todo!()` cites the exact source line.

> The porter still fixes ownership: these `&mut` guesses want lifetimes / owned
> returns. That's the point — the *shape* is free, the judgement is the port.

## Determinism

Same input → byte-identical output (LC_ALL=C, source-ordered, no timestamps /
hostnames / absolute paths — the source appears by its vendor-relative path):

```

$ diff <(scripts/skeleton-gen.sh "$f") <(scripts/skeleton-gen.sh "$f") && echo identical
identical
```
